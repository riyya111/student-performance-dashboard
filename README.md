
#Student Performance Analytics Dashboard

An interactive Business Analytics project built using Python, Pandas, Plotly, and Streamlit.

## Project Overview
This dashboard explores student academic performance and helps identify patterns across different factors.

## Features
- Total number of students
- Overall average score
- Highest and lowest scores
- Average scores by subject
- Gender and test preparation filters
- Student performance records

## Technologies Used
- Python
- Pandas
- Streamlit
- Plotly

## Dataset
Students Performance Dataset from Kaggle.

## How to Run Locally
1. Install the required packages:
   `pip install -r requirements.txt`
2. Run the dashboard:
   `streamlit run app.py`

## Project Purpose
Created as a hands-on Business Analytics portfolio project to practice data cleaning, exploratory data analysis, visualization, and dashboard development.
